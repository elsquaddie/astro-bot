# Telegram I18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Russian and English Telegram UX with persisted user language and independent verification.

**Architecture:** Add a focused `src/bot/i18n.py` translation module, persist `User.language_code`, and route bot handlers through localized helpers. Keep domain records language-neutral and translate only at the Telegram boundary.

**Tech Stack:** Python, aiogram, SQLAlchemy, Alembic, pytest, existing `scripts/verify_mvp.py`.
